# Don’t Make Me Think — for marketing copy

Based on Steve Krug’s principles applied to **selling pages** (not app chrome alone).

## Core laws for words

1. **Don’t make me think**  
   If the visitor has to decode what you sell or what to do next, the copy failed.

2. **Design for scanning**  
   People don’t read marketing pages. They scan. Win at:
   - H1 (job + who)
   - Sub (stakes or proof in one line)
   - Bullets (concrete, parallel, short)
   - CTA label (verb + object: “Copy install”, not “Get started”)

3. **Omit needless words**  
   Happy talk, throat-clearing, and “we’re passionate about…” die first.  
   If deleting a sentence doesn’t lose the job or the proof, delete it.

4. **Conventions are friends**  
   Install blocks look like terminals. Pricing looks like pricing. Sample reports look like documents.  
   Novelty in *structure* costs comprehension — spend novelty on *proof*, not on reinventing “what is a CTA.”

5. **Obvious next action**  
   One primary action. Secondary actions stay visually quieter and later.

## Marketing-specific tests

| Test | Pass if… |
|------|----------|
| **Billboard** | Drive-by reader gets product job from H1 alone |
| **Mom test (skeptic)** | A non-expert can explain what to do next |
| **Noise** | No section exists only to sound premium |
| **Redundant** | Hero, mid-page, and close don’t say the same paragraph three ways |
| **Trust** | Claims attach to something visible (report, command, path) |

## Hierarchy that converts (scan layer)

```
What it is          → H1
Why care now        → sub (problem or outcome, not both essays)
Proof               → artifact / demo / path
How it works        → ≤3 steps
Act                 → primary CTA
Optional depth      → sample, GitHub, FAQ — after the act is clear
```

## Copy moves that pass Krug

- Name the user and the job: “For founders shipping with AI agents”  
- Point at the object: “Sample report”, “Install”, “Run a panel”  
- Prefer nouns you can click over abstract value (“Fluidity score” > “insights”)  
- Cut “and more”, “etc.”, feature laundry lists  

## Copy moves that fail Krug

- Clever headlines that hide the product  
- Two competing CTAs above the fold  
- “Learn more” with no object  
- Long origin stories before the install  
- Metaphor-only demos with no real artifact  

## Density

If the page feels full:

1. Delete a section  
2. Merge two sections that share a job  
3. Shorten lines  
4. Only then add a proof element if something essential is missing
