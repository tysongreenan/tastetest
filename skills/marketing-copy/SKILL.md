## Workflow (Isa)

1. Read run-state: intent, preserve, priority persona.  
2. Fill SB7 map ([storybrand.md](references/storybrand.md)).  
3. Scan check ([dont-make-me-think.md](references/dont-make-me-think.md)).  
4. Propose 2+ product-show modes ([product-show.md](references/product-show.md)).  
5. Draft scan-layer copy only; cut before add.  
6. Handoff to Prose (polish) · Craft (demo DNA) · Frontend (after design brief) · PMs (voice).

## Guardrails

- Customer = hero. Brand = guide.  
- One primary CTA.  
- Real proof over metaphor.  
- No feature-card factory.  
- Preserve install / conversion path.
